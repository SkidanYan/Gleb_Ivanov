# Favicons checklist

Положи сюда файлы с точными именами:

1. `favicon.ico`
   - внутри размеры: `16x16`, `32x32`, `48x48`

2. `favicon-16x16.png`
   - размер: `16x16`

3. `favicon-32x32.png`
   - размер: `32x32`

4. `apple-touch-icon.png`
   - размер: `180x180`

5. `android-chrome-192x192.png`
   - размер: `192x192`

6. `android-chrome-512x512.png`
   - размер: `512x512`

7. `site.webmanifest`
   - можно добавить позже, когда подключим PWA

Рекомендуемый исходник для экспорта:
- квадрат `1024x1024` (или минимум `512x512`)
- без мелких тонких деталей, чтобы иконка читалась в `16x16`
